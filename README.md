# Análise de Dados — E-Commerce Olist

Projeto prático de Data Analytics desenvolvido como Tech Challenge I da FIAP, analisando a base de dados pública da Olist para identificar gargalos logísticos e o impacto dos prazos de entrega na satisfação dos clientes.

## O Que Foi Analisado?

A Olist faturou mais de **R$ 16 milhões** no período analisado, porem o crescimento acelerado trouxe problemas nas entregas:
* **Impacto do Atraso:** Quando o pedido é entregue no prazo, a nota média é de **4,2 estrelas** (60% da nota de 5). Quando há atraso, a média cai para **2,0 estrelas** (quase 60% avaliam com nota 1).
* **Problema Geográfico:** Mais de **90% dos vendedores** estão concentrados no Sul e Sudeste, enquanto os clientes estão espalhados pelo Brasil inteiro.
* **Gargalos Críticos:** 
  * **Roraima (RR):** Maior tempo médio de entrega do país (**28 dias**).
  * **Alagoas (AL):** Pior taxa de pontualidade (**24,5% dos pedidos atrasam**).
* **Solução Proposta:** Criação de um Centro de Distribuição (CD) no Nordeste com foco nas categorias de maior giro nos últimos 120 dias (*Beleza & Saúde*, *Cama, Mesa e Banho*, *Informática*).
